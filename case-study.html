02

用户痛点与产品机会

从创作者在设计到打印流程中的真实阻碍出发，识别产品切入点。

核心痛点

  • 1.用户能力分层明显：专业用户通常借助专业建模软件完成设计，再上传模型进行打印；普通用户则受建模与操作门槛限制，难以开始创作，部分消费级打印机购入数月后便可能闲置。
  • 2.社区模型使用门槛高：部分社区模型虽支持参数化编辑，但缺乏统一的交互规范，不同模型的操作界面各异，使用说明也往往过于专业，增加了理解与使用成本。
  • 3.AI 生成模型难以继续编辑：AI 生成的模型缺乏便捷的后续编辑能力，用户难以进一步调整结构与参数，限制了创意的深化与定制。
  • 4.创作与打印流程割裂：创意、建模、切片、打印与分享分散在不同工具或平台中，工具切换与文件、参数迁移增加了操作成本。
  • 5.打印试错成本高：切片参数复杂，打印结果难以提前准确判断；发生失败后，问题定位与反复调试也增加了时间和耗材成本。

产品机会

  • 1.双模式设计，兼顾专业创作与大众上手：为专业用户提供更高的创作自由度，为普通用户提供更简单的操作路径，降低入门门槛，帮助用户更顺利地完成打印。
  • 2.面向普通用户的低门槛参数化模板：提供操作简明、参数可调的创作模板，让普通用户无需从零建模，也能按需调整并完成个性化创作。
  • 3.AI 辅助创意共创：将 AI 融入创意生成与建模流程，拓展创意探索方式，并让生成结果能够继续编辑与优化。
  • 4.一体化创作平台：打通「创意 → 建模 → 切片 → 打印 → 分享」完整流程，减少工具切换与文件迁移，让创作和打印衔接更顺畅。
  • 5.虚拟打印与预览：在实际打印前预览模型与打印过程，辅助识别潜在问题，降低试错成本，提升打印准备的可控性。

PROJECT 02

工业微型无人机应急搜救方案

面向地震废墟搜救场景的微型无人机系统概念方案，旨在支持救援队伍在 无 GPS 的复杂空间中开展生命探测与现场勘察。 分析依据来自场景分析、竞品研究，以及地震救援与无人机救援纪录片。

场景分析 用户旅程 地面站原型 高保真概念界面已完成
01

场景分析与问题定义

地震废墟搜救中，救援队伍需要在结构不稳定、视野受限且无 GPS 信号的 废墟空间内完成生命探测与现场勘察。本章基于场景分析与纪录片观察， 将「风险评估 → 实施搜救」环节的核心问题归纳为四个能力缺口——

作业环境约束

昏暗狭窄、断电与弱信号、路线复杂、高温、有毒气体、结构不稳定（共六项）。

＋展开六项环境约束

1. 救援环境昏暗、狭窄

2. 电源被切断、信号不佳（无公网 / 无 GPS）

3. 驾驶路线复杂易出错

4. 高温

5. 有毒气体

6. 废墟结构不稳定，存在二次坍塌风险

核心问题 · 四个能力缺口

进得去——人员贸然进入盲区风险极大，传统无人机体积大、难以深入缝隙

看得清——废墟内部低光、高粉尘，普通摄像头难以获得可用画面

定位准——无 GPS 与信号遮挡下常规导航失效，坐标传递低效易错

撤得回——画面卡顿、失控与续航限制带来坠机风险与决策焦虑

02

竞品分析

聚焦四家直接竞品的代表机型，围绕无 GPS 环境定位、狭小空间通过性、探测载荷与地面站协同等维度对比。 基于竞品研究观察，方案聚焦三个待验证的机会方向：

1. 超微型穿缝＋无 GPS 自主飞行

素材范围内未见同时明确覆盖两项能力的公开机型记录。本方案的核心概念方向，需技术可行性验证。

2. 面向搜救任务流的指挥端整合

竞品地面站公开功能多为通用多机协同与数据回传；围绕"建模划区 → 穿缝侦查 → 目标定位 → 力量调度 → 战报生成"任务流的深度整合未见公开记录，需与实际救援工作流对照验证。

3. 兴奋型能力差异化

3D 空间实时建模、搜救路径智能推荐（Kano 兴奋型需求）在竞品公开能力中未见对应，可作为概念方案的演示重点；能力本身待设计、待验证。

用户角色与任务需求

识别搜救任务中的关键角色及其目标、任务与痛点。

现场指挥官（主要用户）

目标：快速、安全地定位幸存者，完成搜救任务闭环。

核心需求：全局态势可视化；目标精准定位与坐标传递；设备状态透明；任务数据自动汇总成报。

＋展开关键任务

关键任务：风险评估、划定重点搜救区域；监控回传画面、指挥飞行器入缝；确认目标、标记坐标；调度突击组破拆；导出数据、向上级汇报。

一线搜救员

目标：安全、稳定地操控设备完成侦查任务。

核心需求：易上手、飞行稳定、画面清晰实时；异常时有明确的设备自主行为预期。

＋展开关键任务

关键任务：按指令操控无人机（或监控自主飞行）进入狭窄空间；观察回传画面、发现疑似目标。

后勤保障人员

目标：保障设备随时可用、任务连续。

核心需求：长航时（设计目标，指标待定）；便携运输；快速换电与检修流程；设备状态可检查。

＋展开关键任务

关键任务：电池更换与续航管理；设备运输、检修与维护。

04

现场指挥官用户旅程

沿搜救任务流程拆解现场指挥官的关键动作、触点与情绪。

1

抵达与快速评估

核心动作：开展风险评估，确定重点搜救区域

主要痛点：宏观视角缺失，人员贸然进入盲区风险极大

＋展开阶段详情

😟 焦虑 / 迷茫

行为：开展风险评估、判断二次坍塌风险；听取汇报，确定重点搜救区域

痛点：宏观视角缺失，无法第一时间构建废墟 3D 模型；人员贸然进入盲区风险极大

机会：集群快速扫描生成废墟外部全景图，辅助划分搜救优先级

2

部署与侦查

核心动作：下达起飞指令，监控回传画面，指挥飞行器入缝

主要痛点：体积大难入缝、无 GPS 易迷航、低光粉尘看不清

＋展开阶段详情

😰 紧张 / 担忧

行为：下达起飞指令，通过平板端监控回传画面，指挥飞行器进入狭窄缝隙

痛点：传统无人机体积大难入缝、无 GPS 易迷航；低光粉尘下看不清；专注飞控易漏画面细节

机会：微型化＋无 GPS 自主飞行；热成像辅助观察温差特征、AI 框选人形 / 体温（待验证）

3

目标确认与定位

核心动作：发现疑似目标，悬停确认并标记坐标

主要痛点：画面抖动难对焦，缺乏精准坐标指引

＋展开阶段详情

😃 兴奋 / 希望

行为：发现疑似目标，查看热成像与 AI 识别框，指挥悬停确认并标记坐标

痛点：画面抖动难以对焦判断；缺乏精准坐标，难以快速指引地面人员

机会：机载 AI 标记目标并生成 3D 坐标点；双机协同补光确认

4

决策与力量调度

核心动作：通知突击组破拆进入，持续监控环境变化

主要痛点：语音描述位置低效，环境变化难实时掌握

＋展开阶段详情

😐 专注 / 谨慎

行为：基于标记点通知突击组破拆进入，持续监控周边环境变化

痛点：语音描述位置效率低；无法实时掌握救援队员进入后的环境变化

机会：破拆点实时标注推送至突击队终端；有害气体数据实时回传

5

任务复盘与数据归档

核心动作：回收无人机，导出数据并向上级汇报

主要痛点：数据碎片化难成战报，续航短频繁换电

＋展开阶段详情

😌 释然 / 疲惫

行为：回收无人机，导出搜索路径与探测记录，向上级汇报

痛点：数据碎片化，难以形成完整搜救战报；续航短，频繁换电打断搜救节奏

机会：一键生成区域覆盖热力图与搜救报告；长航时设计目标（指标待定）
